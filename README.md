# cristlian.github.io

Personal site of Yifei (Crist) Lian, AI engineer in London.

**Live:** https://cristlian.github.io

It's one static page with no build step. The markup, styles and canvas visualizations all live in `index.html`, and the only external resource is Google Fonts.

| File | What it does |
| --- | --- |
| `index.html` | The whole site |
| `og.png` | 1200 × 630 preview image for LinkedIn, Slack and email |
| `favicon.svg` | Browser tab icon, with a dark-mode variant |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

GitHub Pages serves the `gh-pages` branch. `master` holds the same files.
